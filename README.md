## About

I'm a software engineer with **10 years of experience** building and maintaining production web applications, mobile products, and backend services.

My work sits at the intersection of **mobile engineering, backend systems, and developer productivity**. I enjoy taking features from business requirements to production—from application architecture and API design to database consistency, testing, observability, and releases.

I'm also an AI-assisted engineer, using tools such as Cursor, GitHub Copilot, and LLMs to accelerate development while maintaining control over architecture, code quality, security, and business logic.

- 📱 **Mobile:** React Native, TypeScript, Expo, native integrations
- ⚙️ **Backend:** Node.js, REST APIs, authentication, data modeling
- 🏗️ **Architecture:** Modular systems, maintainability, scalable application design
- ☁️ **Infrastructure:** AWS, GCP, CI/CD, monitoring, production debugging
- 🤖 **AI-assisted engineering:** Context engineering, reusable agent instructions, AI-assisted testing and code review
- 🚚 **Domain experience:** Logistics, last-mile delivery, fleet tracking, and enterprise workflows
